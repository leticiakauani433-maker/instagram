# Meu Feed em Flutter 📱

## Sobre o projeto
Aplicativo desenvolvido em Flutter utilizando a linguagem Dart, com um feed dinâmico inspirado no Instagram.

## Funcionalidades
- Listagem de publicações com fotos.
- Exibição de ícone de perfil.
- Botão de curtir com contador de curtidas.
- Botão de comentários.
- Botão de compartilhar.
- Rolagem vertical entre publicações.

## Tecnologias utilizadas
- Flutter
- Dart
- Material Design

## Imagens
As imagens são utilizadas nas publicações do feed e estão organizadas na pasta `imagens/`.

## Como executar
1. Instale o Flutter.
2. Clone o repositório do GitHub.
3. Abra a pasta do projeto no VS Code.
4. Execute o comando:

```bash
flutter pub get
```

5. Inicie o aplicativo:

```bash
flutter run
```
